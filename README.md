# 👗 WhatToWear – เว็บไซต์แนะนำการแต่งกายเบื้องต้น

✨ โปรเจกต์นี้ถูกออกแบบมาเพื่อช่วยให้ผู้ใช้งานเลือกชุดแต่งกายได้เหมาะสมกับแต่ละโอกาส ไม่ว่าจะเป็นวันทำงาน วันเที่ยว หรือวันสำคัญต่าง ๆ โดยใช้เทคโนโลยี Java, JSP และ CSS ในการสร้างเว็บไซต์ที่ใช้งานง่ายและดูดี 💻💕
