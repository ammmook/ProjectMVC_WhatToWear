# 👗 WhatToWear – เว็บไซต์แนะนำการแต่งกายด้วย AI

✨ **WhatToWear** เป็นเว็บไซต์ที่ช่วยให้คุณเลือกชุดแต่งกายได้อย่างมั่นใจในทุกโอกาส โดยใช้เสื้อผ้าที่คุณมีอยู่จริงมาจับคู่ให้เหมาะสมกับสถานการณ์ต่าง ๆ เช่น:

- 👔 ทางการ – สำหรับงานประชุม สัมภาษณ์ หรือโอกาสที่ต้องการความเรียบร้อย
- 👕 กึ่งทางการ – สำหรับกิจกรรมที่ต้องการความสุภาพแต่ไม่เป็นทางการมาก
- 🩳 ลำลอง – สำหรับวันสบาย ๆ เช่น ไปเที่ยวหรือพักผ่อน

ระบบจะช่วยวิเคราะห์รูปแบบเสื้อผ้าของคุณด้วย **AI อัจฉริยะ** เพื่อเสนอชุดที่ดูดี เข้ากับบุคลิก และเหมาะกับโอกาสนั้น ๆ โดยไม่ต้องซื้อเสื้อผ้าใหม่ 🎯

## 🛠️ เทคโนโลยีที่ใช้

- ☕ **Java Servlet & JSP** – สำหรับการจัดการฝั่งเซิร์ฟเวอร์
- 🎨 **HTML/CSS** – เพื่อออกแบบหน้าตาเว็บไซต์ให้สวยงาม
- 🤖 **AI Model** – วิเคราะห์รูปแบบเสื้อผ้าและแนะนำชุดที่เหมาะสม
- 📦 **Git LFS** – สำหรับจัดการไฟล์วิดีโอขนาดใหญ่
